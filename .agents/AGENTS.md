# Regras e Diretrizes do Projeto VibeVoice BR

## Controle de Versão e Envio para o GitHub
- **Push para o GitHub:** NUNCA execute `git push` ou envie alterações para o repositório remoto do GitHub automaticamente sem a autorização ou comando explícito do usuário.
- Faça os testes e alterações locais primeiro e aguarde a solicitação/confirmação do usuário antes de enviar commits/tags para a nuvem.
